## 下午 Bug 修复（16:00-16:30）

### 第一轮修复（5 个）

1. **WebSocket 事件桥完全失效** (CRITICAL):
   - `events.py` 的 `emit()` 传递 `Event` 对象给处理器，但 `websocket.py` 的 `_on_event` 定义为 `dict` 参数，调用 `.get("task_id")` 导致 `AttributeError`
   - 修复：将 `_on_event` 参数改为 `Event` 对象，正确读取 `event.task_id` / `event.data` / `event.type`

2. **管道重复执行** (MAJOR):
   - `_run_pipeline_bg` 顺序调用 `stream_pipeline()` 然后 `run_pipeline()`，等于跑两遍完整流程，LLM 调用翻倍
   - 修复：让 `stream_pipeline()` 返回 `Tuple[List, PipelineState]`，调用方只跑一次

3. **code_executor AST 校验文件被静默丢弃**:
   - `execute_code()` 中 AST 校验失败的文件被跳过写入但不记录 `FileExecResult`，导致 `total_files` 统计偏大、`success` 标志不准
   - 修复：AST 失败时同样创建 `FileExecResult` 记录到 `results`

4. **第三方库缺失被误判为代码质量失败**:
   - 生成的代码导入 numpy/pandas 等第三方库时，`import` 测试失败被当作代码错误，导致自愈循环无效触发
   - 修复：用正则检测 `ModuleNotFoundError`，匹配时设置 `import_is_third_party=True` 且 `import_ok=True`

5. **验证失败不发送事件**:
   - `_verify_and_heal` 只打 log，Dashboard 看不到验证状态
   - 修复：失败时 emit `NODE_FAILED`，完成时 emit `NODE_COMPLETED` 含 `verdict`/`summary`

### Bug 8: FOREIGN KEY constraint failed

### Bug 9: LLM 调用无限挂起
- 根因：DashScope API 偶发超时，httpx timeout=120 对新版 httpx 不兼容；concurrent.futures ThreadPoolExecutor 在 Windows 上无法中断阻塞 socket
- 修复：ChatOpenAI timeout 改为 httpx.Timeout(connect=15, read=90, write=15, pool=10)；chat() 所有 fallback 耗尽后降级 DryRun 而非 raise
