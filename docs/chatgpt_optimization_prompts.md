## 实操技巧

1. **分批发送代码**：ChatGPT 单次对话有 token 上限，建议每次发送 2-3 个文件（不超过 1500 行），等分析完再发下一批。
2. **先诊断后开方**：不要一上来就让 ChatGPT 改代码。先用阶段 1-3 做完诊断，拿到完整的问题清单后再进入阶段 4 的迭代。
3. **保留原始代码备份**：ChatGPT 给出的重构代码一定要先跑测试（`pytest tests/`），确认 438 项测试全绿再合并。
4. **追问具体数字**：当 ChatGPT 说"显著提升"时，追问"具体提升多少？基于什么测试场景？请给出量化数据"。
5. **交叉验证**：重要架构决策不要只听 ChatGPT 一面之词。可以同时在 Claude / Gemini 上跑同样的 Prompt，对比方案差异。
6. **上下文管理**：如果对话过长导致 ChatGPT 遗忘项目上下文，重新粘贴阶段 0 的上下文注入 Prompt。
